# 📡 Miniaturized Jug-Shaped CPW-Fed UWB Antenna for Wireless Communication

## 📝 Overview
This project presents the design, simulation, and evaluation of a **jug-shaped Coplanar Waveguide (CPW)-fed Ultra-Wideband (UWB) antenna**, aimed at addressing challenges in miniaturization and wideband performance for wireless applications like **Wi-Fi, 5G, radar, and satellite communication**.

## 🎯 Objectives
- Design a compact, high-performance CPW-fed UWB antenna
- Simulate and analyze return loss, gain, efficiency, VSWR, Z-parameters
- Fabricate the antenna and validate it using lab measurements

## 🛠️ Tools & Technologies Used
- **Simulation Software**: CST Studio Suite 2019
- **Substrate Material**: FR4 (εr = 4.4, thickness = 1.6 mm)
- **Testing Equipment**: Vector Network Analyzer (R&S ZNB 40)

## 🧪 Key Performance Metrics
| Parameter           | Result                               |
|---------------------|--------------------------------------|
| Frequency Bands     | 2.64–3.69 GHz, 4.65–5.07 GHz, 6.58–9.42 GHz |
| Return Loss (S11)   | < -10 dB across bands                |
| Realized Gain       | Peak ~2.5 dBi                        |
| Radiation Efficiency| ~91%                                |
| Substrate           | FR4 (εr = 4.4, tanδ = 0.025)         |
| VSWR                | Below 2 in operational range         |

## 🧠 Key Takeaways
- The jug-shaped design achieved wideband performance in a compact form.
- Achieved < -10 dB return loss across three major bands (S, C, and X).
- Suitable for next-gen devices due to its small footprint and high efficiency.

## ⚙️ Applications
- Wi-Fi (2.4 & 5 GHz)
- 5G mid-band (4.6–5.1 GHz)
- Satellite (C/X bands)
- Military radar & sensing systems
- IoT & smart devices

## ➕ Advantages
- Ultra-wideband impedance matching
- Compact size with FR4 substrate
- High radiation efficiency and low group delay
- Fabrication feasibility with low-cost materials

## ⚠️ Limitations
- FR4 introduces moderate dielectric loss at higher frequencies
- Limited power handling
- Precision required in fabrication
